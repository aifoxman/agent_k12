# 家长端 Android App 交互设计

状态：v0.3，供评审。基于 [MVP 设计草案](mvp-design.md)、[同类产品研究](comparable-products-review.md)和[双端语音交互](voice-interaction.md)；首批仅支持 Android 手机，设备闭环先用一个家庭、一名孩子、一台小米 Pad 6 验证。家庭作业是首要场景，不预设单一优先科目。

## 页面结构

| 页面 | 主要内容与操作 |
| --- | --- |
| 今日 | 当前作业会话与相机状态、当日任务、孩子的求助、待家长确认项；作业会话进行中才显示“查看纸面”入口。 |
| 新建任务 | 粘贴群作业文字，逐项核对科目、内容和截止时间，再发布到平板；可用语音朗读核对和口述修改。 |
| 纸面查看 | 直接展示实时纸面、连接状态和孩子端的查看提示；可请求临时高清定格图、画圈标注、发起语音或结束查看。语音单独显示接通与静音状态。 |
| 每日回顾 | 展示任务状态、学习时长、求助次数、逐页批改的原始截图与对应标记、孩子反馈及待确认项；家长可复核批改，不依据镜头画面自动判定任务完成。 |
| 家庭与设备 | 查看孩子年级、可选教材版本、绑定平板和当前设备状态；可关闭主动卡题提醒，解除绑定或删除学习记录。具体账号登录方式待定。 |

底部导航保留“今日”“回顾”“家庭”三个入口；新建任务和纸面查看从“今日”进入。今日进度、求助和待确认项可语音播报，关键确认也可口述，但识别结果要复述后再提交。求助提醒可通过通知送达，进入 App 后的记录始终可见。

## 首次使用与任务闭环

1. 家长登录后在手机端选择“绑定平板”；平板显示一次性配对码。家长输入代码，双方核对孩子与设备信息，再完成绑定。过期或错误的代码可重新生成。
2. 家长从群消息粘贴作业文字，编辑科目、内容和截止时间；可让 App 朗读核对或口述修改。家长确认最终内容后才同步；首版不导入群截图。
3. “今日”展示每项任务的`待开始 → 进行中 → 待家长确认 → 已确认`状态。孩子在作业结束反馈中核对机器观察并勾选任务后进入“待家长确认”；家长可按题号查看纸面复查依据、纠正识别结果，确认完成或退回并附上简短说明。求助和“疑似写完”是独立标记，不替代完成状态。
4. 家长与孩子同时修改同一任务时，以服务端版本为准；较旧的修改先显示冲突，再让家长检查并重新提交，避免静默覆盖。

## 纸面查看与语音指导

家长在进行中的作业会话点“查看纸面”后，依次看到“请求中”“连接中”“正在查看”；服务端核验家庭身份、设备绑定和活跃会话后直接连接，不等待孩子确认。孩子端始终显示并播报查看状态，提供暂停与结束作业入口；暂停后家长端立即停止画面。

家长点“画圈”后在直播画面上圈出题目、字句或步骤；标注同步叠加在孩子平板的纸面预览中，不会实际画到作业本上。标注使用画面坐标并随画面缩放换算；翻页、镜头移动或结束查看时清除旧标注。家长可边画圈边用语音说明题号或步骤，平板显示并播报“家长正在标注”，孩子可放大局部。

家长点或说“语音指导”后请求麦克风通话；未接通前不传送语音。通话中提供静音与结束按钮，结束语音后仍可继续查看纸面。家长退出查看页、孩子结束作业会话或任一端主动结束时，关闭画面、标注和通话并使本次访问凭证失效。重新查看必须发起新请求。音视频不默认录制；家长本人视频不列入首版。

家长查看的进度提示应标明来源，例如“孩子已勾选”“系统观察到第 3 题有书写变化”“待家长确认”。纸面分析不确定或不可读时显示“未能判断”，不生成确定的完成或掌握结论。

| 异常状态 | 家长端反馈与恢复操作 |
| --- | --- |
| 平板离线或未开始学习 | 显示设备／会话状态，保留任务与回顾入口；可刷新状态。 |
| 孩子暂停或结束作业 | 立即停止画面、标注与通话，显示“作业已暂停／结束”；恢复后可重新请求。 |
| 相机不可用或权限未开 | 显示平板端需处理的原因；仍可查看任务和求助记录。 |
| 网络断开或连接失败 | 停止画面、标注与语音，显示重试入口；重试时重新校验活跃会话与设备绑定。 |
| 账号失效或设备解绑 | 退出查看页，要求重新登录或绑定；不展示缓存画面。 |

## 试点验收

- 一部 Android 手机通过蜂窝网络可完成绑定、粘贴文字建任务、孩子提交最终作业后的确认和日报查看；关键内容可朗读核对。
- 作业会话期间可直接接通直播、画圈和语音；孩子端能看到查看／标注／通话状态，并可暂停或结束作业。
- 标注与纸面位置在双端一致，翻页后不残留；断网、会话结束与设备解绑后，家长端画面、标注和语音停止。
- 幼儿园、小学、初中各用一份真实家庭作业检查文案、语音与任务流程；学习记录默认满60 天自动删除。
