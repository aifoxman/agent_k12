# 作业任务发布、提交与确认

## 任务状态

`todo → doing → awaiting_parent → confirmed`。家长退回时为 `needs_revision`，孩子补做并再次提交后回到 `awaiting_parent`。家长也可说明原因取消任务。结束相机会话不会自动确认任务，只有家长确认才是完成；AI 判断始终只是建议。

## 发布与提醒

家长粘贴群作业文字，核对拆分后的每项任务，设置整批精确截止时间并按需逐项覆盖科目和时间。截止时间最多在发布后 60 天内。孩子端前台按事件提醒新任务、退回、截止前一小时和逾期任务；同类任务合并播报，可稍后 30 分钟，不打断辅导或通话。操作词同时可点击或语音回应。系统推送暂未实现，应用关闭时不会提醒。

## 提交与复核

孩子说“提交作业”或点任务卡。纸面任务先经相机收集稳定、完整的最终页面，自动裁剪与去重；孩子核对冻结缩略图后一次提交，单页走同一快捷流程。无法拍照时必须解释原因，交由家长人工核对。每次提交记录独立截图、说明和时间；首次提交时间决定是否按时，家长审核延迟不改变它。AI 自动查看清晰度、页数和明显遗漏，不自动判任务完成。家长可按需对保存的最终截图发起完整逐题批改、查看原图标记并校对单题结果。家长查看任务相关辅导、观察、自述与批改记录后确认，或写清补做原因后退回；批量确认仅处理当前仍待审的提交。

## 数据边界与验收

任务、提交截图、辅导与批改记录从各自创建起最多保留 60 天；家长可提前清空全部家庭作业历史。到期未确认任务删除内容，仅累计“未确认”数量。自动观察的临时图像与连续直播视频不保存，原始语音不保存。已覆盖发布幂等、家庭隔离、重新提交、批量确认原子性、人工校对和到期归档的 API 测试。双端发布、前台提醒、真实纸面提交、退回、再提交和确认已在真机走通；自动多页翻页捕获、第三方模型完整批改准确度和后台推送仍需验收。
