# 长期设计约束：面向 K12 通用作业

本约束适用于孩子端、家长端、服务端、模型提示词、测试与后续迭代。当前实拍的少量语文和数学页面只用于发现问题和回归验证，**不能据此把某道题的文字、答案、选项、学科或页码写死在业务代码或提示词里**。

## 教师式学习目标

本项目以在家庭学习中承担优秀辅导老师的具体工作为长期目标：引导读题、分析、尝试、复检与迁移，培养学习习惯和方法，并向家长呈现可核对的学习进展。批改仅用于发现学习机会。每个新功能应说明怎样支持孩子独立思考、怎样回应孩子当前想法、何时让家长介入；设计时核对[教师式学习陪伴准则](teacher-led-learning.md)中的教育研究与同类产品证据，再用多学科真实作业验证。不能把一次模型输出等同于教学效果。

## 批改依据

每次从本次截图动态识别题干、操作要求、图表、选项、孩子书写与已有批改痕迹，并将证据对应到具体题目。判断前核对题目和选项本身是否成立，再核对答案与学科知识；已有对勾、模型上次结论、其他选项明显不符，都不能单独证明孩子答对。题干不全、字迹不清、多个答案合理或题目本身有疑点时，返回“无法判断”或“需讨论”，说明缺少什么依据。

## 纸面准入与局部限制

纸面检查要判断被挡住的**信息**，而不是只检测遮挡物。若笔、尺或手仅盖住未填写的空白括号、答题框或纸边，题干、条件、图表和孩子已写内容仍可读，就允许进入作业，也可以辅导该题。透明物与图形重叠时，若图形含义仍可辨认，也不应阻断。只有具体题干、条件、图形含义或已写内容确实无法读取时，才指出缺失的信息并要求调整；不能只报告“某题被遮住”。提示和批改都不能猜被盖住的内容。这条规则适用于各学科和题型，不能针对测试页某个题号写死例外。

## 实现与验证

- 用通用的页面检测、局部放大、原图上下文、逐题证据和结果复核机制解决识别问题；避免为单个汉字、算式或测试页增加例外规则。
- 学科、年级、教材、页码和题型应来自用户配置或本次纸面，不用测试页限定可处理范围。新增学科或题型时沿用同一证据和不确定性规则。
- 提示词描述核对步骤及输出格式，不能包含当前样本的特定答案、题目文字或“重点防某一题”的补丁。
- 测试覆盖不同学科、年级、题型、清晰度、跨页题干和有误试题。样本回归只证明该样本没有复现错误；上线判断需要独立、多样的人工核对集。

改动批改逻辑前先检查是否违反以上约束，并在[真机验收记录](device-validation.md)记录实际覆盖和限制。
