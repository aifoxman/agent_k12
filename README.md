# 纸间 · 家庭作业陪伴 MVP

一套面向单家庭试点的孩子端 Android 平板应用、家长端 Android 手机应用和独立 API。孩子在小米 Pad 6 上主动开始作业；进入及暂停后恢复会话前需由视觉模型确认纸面完整、清晰。作业中用沉浸式大画面与两侧悬浮控件，一次提交当前试卷的自动分页批改；孩子可申请家长授权，查看带纸面标记的逐题批改与解题分析。家长粘贴群作业文字、远程按需查看纸面、画圈、语音通话，并确认任务完成。

**项目目标**：在家庭学习场景承担优秀辅导老师的读题、分析、示范、引导独立思考、复核、习惯培养、限时练习和学习反馈等工作。当前 MVP 从作业陪伴与分层提示起步，批改服务于学习诊断；后续设计与验收均参照[教师式学习陪伴准则](docs/teacher-led-learning.md)，不以一次模型回答代替真人教师效果评估。

**长期设计约束**：少量试卷仅供回归，不得把样本题目、答案或选项写死进代码和提示词。任何批改改动须遵守[K12 通用设计约束](docs/design-principles.md)。

**辅导的两个书写区域**：思考草稿记录方法、理由和关系；具体解题步骤、条件圈划及图形勾勒优先落在本次作业截图，可靠位置不足时才使用明确标注的示意。辅导要把当前方法的因果讲清，完整示范可连贯解题并检查；孩子明确只要提示或不报答案时按其要求。退出辅导、返回实时画面、暂停和重启后默认隐藏全部辅导图层；已保存的分步资料仅由“回看上次辅导”主动打开。新讲解保存文字及矢量步骤，不保存辅导照片，也不把旧圈划叠到新相机；旧记录仅恢复已有讲解文字。

**每题至多两层帮助**：默认“读题与思路”，在原题圈划条件并讲清可执行的方法；孩子已明白即可回去写。仍需帮助时点“解题思考”，直接听完整过程、可靠结论与检查，不再增加第三轮起步引导。两层都审题圈划；第二层复用同题冻结照片，由服务端校验原讲解、任务及图像摘要。明确要求完整解题可直接进入第二层，明确“不要答案”仍优先。讲完不自动开麦追问，帮助层级与唯一的逻辑步骤进度分别处理。

**分步跟学**：按读懂条件、建立关系、推导计算与检查等教学意图组织连贯步骤，语音开始时呈现对应圈划／草稿。界面只显示一套逻辑步骤进度，上一步、下一步、重讲和草稿共用此进度。默认在短暂停顿后继续，孩子可随时暂停；“再讲这步”和“慢一点”重讲当前逻辑步后停留，不提前推进。按住说话会先中断当前播报。课程保存完整，部分回看和重讲不覆盖完整资料。云端、浏览器与平板原生语音都传递实际语速。

原图保留划线、圈框、箭头与短标签；操作句和算式集中放在题图下的“原题解题过程”区，按实际字号自然换行，可滚动、收起，不能浮盖题干或图形。思考理由仍保留在草稿。

默认使用 1.0 倍正常语速，“慢一点”使用 0.85 倍；片段间约停 250 毫秒，逻辑步间约停 400 毫秒，实际推进还需等待当前语音及书写完成。小学讲解优先用图上可指出的对象和等份关系，必要符号先解释含义；不按固定字数拆散关键因果。完整方法／示范使用家庭设置的“整页解题”模型，普通线索和独立尝试回应使用“互动提示”模型；不因此新增一轮模型调用。

2026-10-25 的正常语速、连贯步骤与辅导布局调整见[本轮验收记录](output/acceptance/teacher-continuity-20261025-143900/verification.json)。记录分别列出受控回放、真实模型、真机结果及仍待完成的检查；原图和笔迹必须同尺寸映射，相关示意在后续解释中也须保持完整。

## 结构

- `src/client/`：两端共用的 React 界面。Android 包使用 `?mode=child` 或 `?mode=parent` 启动。
- `src/android/child/`、`src/android/parent/`：两个独立 Android 安装包；`common/` 是 WebView、相机/麦克风权限及原生语音桥。
- `src/k12_server/`：FastAPI、SQLite、模型适配和 WebRTC 信令。
- `tests/`：关键业务、家庭权限、批改截图绑定与60 天清理的接口测试。
- `assets/`：两端共用的静态图标。
- `docs/`：交互设计、竞品研究、[任务闭环](docs/task-review-workflow.md)、[K12 通用设计约束](docs/design-principles.md)、[实现复盘](docs/implementation-review.md)及[待优化功能清单](docs/optimization-backlog.md)。

## 本地运行

需要 Python 3.11+、[uv](https://docs.astral.sh/uv/)、Node.js/npm。首次运行：

```powershell
Copy-Item .env.example .env
uv sync --extra dev
npm install --prefix src/client
```

在 `.env` 中设置随机的 `APP_SECRET`（至少 32 字符）、`AI_API_URL`、`AI_API_KEY`、`AI_MODEL`。`AI_API_URL` 应填写完整的 Chat Completions 地址（例如 `https://example.com/v1/chat/completions`），模型需支持视觉消息并返回 JSON。开发时在两个终端分别运行：

家长端可分别设置「整页解题」和「批改与单题复检」模型，分别默认 `gpt-6.1-sol` 与 `gpt-6-astra`。`AI_FAST_VISION_MODEL` 默认 `gpt-6-luna`，用于检查纸面、同页进展核对和提示后的新书写判断；留空则使用 `AI_MODEL`。快模型结果不确定时，准备检查和孩子主动要求的新书写核对会由 `AI_MODEL` 复核。孩子端 APK 内含中文 OCR，仅在本机辅助定位文字区域；是否可以开始仍由服务端视觉模型确认。已有家庭的解题模型选择保持不变，新增批改设置默认为 Astra。若服务商明确返回 `gpt-6.1-sol` 没有可用通道，当前请求回退至 Astra，并在五分钟内优先使用 Astra；AI 用量记录标注实际调用的模型。

小米系统识别服务过早结束或断网时，可在家庭服务端启用本地中文转写：先运行 `uv sync --extra dev --extra asr` 和 `uv run --extra asr scripts/prepare-local-asr.py`，再在 `.env` 设置 `ASR_LOCAL_MODEL_PATH=./data/asr-model` 并重启 API。模型下载到已忽略的 `data/`，录音只发送到当前家庭服务端，服务端内存中转写后丢弃原始音频。也可改用 `ASR_API_URL`（完整的 OpenAI 兼容 `/v1/audio/transcriptions` 地址）、`ASR_API_KEY`、`ASR_MODEL`；两者都配置时优先使用远程地址。家长须在手机首页单独打开“短语音转写”后才会使用独立通道；关闭或模型缺失时仍使用设备系统识别。Android 设备端识别服务报错时会尝试系统默认识别器；两路仍不可用时界面会提示启用短语音转写。独立通道按住期间录完整段，松手发送，最长 30 秒。图像模型配置不能直接充当语音转写配置。

云端播报支持腾讯云流式文本语音合成。先在腾讯云开通服务并确认账户有相应资源，再在 API 服务端设置 `TENCENT_TTS_APP_ID`、`TENCENT_TTS_SECRET_ID`、`TENCENT_TTS_SECRET_KEY`；密钥只留在服务端。使用已有腾讯资源时，可配置以下音色顺序并重启 API：

```dotenv
TTS_PROVIDER=tencent
TTS_QUOTA_MODE=provider
TENCENT_TTS_VOICE_TYPE=502001
TENCENT_TTS_FALLBACK_VOICE_TYPES=501002,101001
```

此示例依次使用超自然大模型音色 1.0（`502001`）、大模型语音合成（`501002`）、通用语音合成（`101001`）。只有当前音色在出声前明确返回资源耗尽时，才尝试下一项；鉴权、参数或临时网络错误不触发该切换，已经出声后也不尝试下一腾讯音色。通用音色使用 16 kHz，服务端将 PCM 转成 Pad 所需的 24 kHz；调用方仍使用同一语音接口。

`TTS_QUOTA_MODE` 默认为 `application`（模板同样默认此值），每个家庭保留 20,000 点应用试用上限；汉字按 2 点计算，不等于腾讯计费点数。设为 `provider` 后使用已配置云账户的资源，不再用应用试用上限拦截，但仍需家长在首页主动开启云端语音，历史应用点数不会清零。页面显示累计应用点数，不推算腾讯剩余额度；实际可用量和费用以腾讯云账户为准。全部配置资源耗尽或服务失败时回退设备系统声音，普通状态刷新不会反复重试已确认耗尽的资源；真实切换额度模式或重新授权后才允许恢复尝试。此配置不购买资源或修改云端付费方式。旧阿里云接入仍可设置 `TTS_PROVIDER=aliyun` 及北京地域的 `TTS_API_KEY`、`TTS_WORKSPACE_ID` 使用。

文生音频接口保持 OpenAI Speech API 形状的 `POST /v1/audio/speech`：家庭设备令牌鉴权，`model=k12-tts`、`voice=teacher-warm-female`；默认流式 MP3，Pad 使用 `response_format=pcm` 的 24 kHz、16 位、单声道音频。支持 `stream_format=audio`、`response_format=mp3|pcm`、`speed=0.5..2`；腾讯最低语速约 0.6 倍，`speed=0.5` 会按 0.6 倍合成。SSE、其他编码和 `instructions` 返回明确错误。腾讯流式文本接口不支持 SSML，发音处理采用纯文本口语化。

```powershell
uv run uvicorn k12_server.app:app --env-file .env --host 0.0.0.0 --port 8000
npm run dev --prefix src/client
```

浏览器访问 `http://localhost:5173/app/?mode=parent` 和 `http://localhost:5173/app/?mode=child`。相机需浏览器安全来源；正式设备试验请使用 HTTPS API 和安装包。USB 联调时，在**调试版** App 中填写 `http://127.0.0.1:8000`；发布版只允许 HTTPS。设备重连会清除 ADB 反向映射，另开终端运行以下脚本持续恢复两端映射（端口应与 API 监听端口一致）：

```powershell
.\scripts\keep-adb-reverse.ps1 -Port 8000 -Serials PAD_SERIAL,PHONE_SERIAL
```

`GET /health` 可检查 API。若 App 显示“无法连接服务”，先确认 API 正在运行、设备已连接，再检查反向映射。未配置视觉模型时账户和任务仍可使用，纸面检查、观察和提示会明确返回 503，不能进入分析会话。

测试阶段可在 API 服务端 `.env` 设置 `CORRECTION_REQUIRE_PARENT_APPROVAL=false` 并重启 API。该服务上的孩子端可直接批改，不再等待家长人工授权；界面由服务端返回的权限状态决定。此设置只跳过批改授权，仍校验家庭、当前设备及进行中的作业会话；暂停或结束后不能继续批改，也不会自动确认任务完成。配置模板默认为 `true`，恢复为 `true` 并重启即可重新要求家长授权；测试模式不会写入或延长家长授权期限。

若平板已绑定其他家庭，先在孩子端「设置 → 更换家长账号」生成 8 位换绑码，再在新家长端「配对平板」输入。码 10 分钟有效；输入前原连接不变，成功后旧会话结束，旧作业记录留在原家庭。

## 试点服务部署

Linux 服务器上将 `.env.example` 复制为 `.env`，设置真实的 `APP_DOMAIN`、`APP_SECRET`、AI 参数和 `TURN_HOST`、`TURN_SHARED_SECRET`、`TURN_PUBLIC_IP`，然后运行 `docker compose -f compose.yaml -f compose.turn.yaml up -d --build`。域名需指向服务器；开放 TCP 80/443/3478 与 UDP 3478、49160–49200。Caddy 为 API 提供 HTTPS，coturn 为不同网络的直播提供中继。API 和 coturn 必须使用相同的 TURN 密钥。此部署模板尚未在当前无 Docker 的开发机上执行。

## 数据与边界

纸面检查判定可读后会直接进入作业，并在后台建立整页题目索引。稳定画面变化时，Pad 用同一张完整截图并行启动题目准备与作答观察。服务端优先预解当前未完成小题，再并发处理其余可读题；索引建好即可供求助使用，无需等待全页解完。同一家庭较早拍摄的相似页面会为本次重新定位提供印刷题参考，题干核对一致时可复用已核对解法；每次仍重新读取孩子的笔迹和进度。题目文字及解法缓存最多保留 60 天，不新增原始截图存储。画线、圈画及主动问询先尝试匹配已建立的题框，证据不足时再调用视觉定位。语音题号可省略上层编号；系统结合整页题号、未完成进度和纸面笔迹定位，冲突时请孩子补充题干。

已核对题目的辅导优先通过 `/v1/hints/stream` 逐段返回语音与图上笔迹。思考草稿解释理由，原题优先承载圈词、划线、边长标记、短操作批注与搬入示意；具体解题操作不默认搬到草稿重画。界面只保留一套解题步骤进度，草稿与原图同步跟随，回看和重讲沿用同一划分。普通线索提示不代写答案，明确要求完整示范且解法可靠时讲清推理、结果与检查；明确不要答案时仍保留结果。历史分步资料供主动回看，普通陪伴、退出辅导、暂停和冷启动默认隐藏，也不自动播音。条件旁的教学勾选只表示使用条件。

数字圈划允许中文数词与阿拉伯数字等价匹配，并保留本句实际说出的词作同步依据。原图算式只取模型已经提交的短批注：全文不对应本句时，可保留本句确实说出的完整算术等式核心，不自动生成新算式；仍须有本次可靠锚点及相应答案权限。

原图锚点先与当次照片笔迹核对；只有局部唯一且连续的可见笔迹才校准线段位置，模糊或有歧义不猜线。像素复核只证明位置支持，不能独立证明文字身份或几何命名。积木等对象题优先核对少量可见区域与关键词，明确需要点边连线时再查精确几何位置。需要补读时，本轮最多一次紧裁剪核对，超时不超过 30 秒及 `AI_TIMEOUT_SECONDS` 中的较小值，按实际裁剪像素边界回映；失败仍保留可靠讲解。旧 `/v1/hints` 接口继续可用。家长可在右上角设置中选择整页解题、题目定位、互动提示的模型，并关闭预解。默认分别为 `gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-luna`；完整方法和示范复用整页解题角色，普通线索使用互动提示角色，低置信度或题意含糊的预解会独立复核。决策模型方案目前仅作为离线评测候选，不进入孩子实时链路。

相机返回全黑画面时，Pad 拦截本次截图并尝试恢复相机，避免错误画面进入缓存。纸面移动后后台最多并行准备两张候选画面；新索引处理期间，仍保留原来已核对的题目供同页求助使用。

孩子求助后，应用结合当前题、纸面和本次对话给出简短引导；孩子可以直接说自己的想法，或继续动笔，无需选择固定口令。口述回答与已核对答案意思等价、且题目定位和判断都可靠时，会明确肯定并用一句话总结；不完整或不确定时继续引导。纸面稳定变化后，应用在后台核对本题是否出现新书写；没有可靠变化时保持安静，新书写也不等于答案正确或孩子已理解。孩子再次求助时接续当前题与此前互动，明确换题时重新定位。提示浮层只显示老师的话和重播入口，完整批改仍由单独的授权流程处理。

家长粘贴群作业后先核对拆分出的任务，为整批设置准确截止时间，也可逐项改科目和截止时间；发布期限最多 60 天。孩子端在应用前台提醒新任务、退回任务和临近截止任务，支持稍后提醒；辅导和通话中不插播语音。孩子完成后说“提交作业”或点击任务卡，系统自动收集稳定画面中的单页或多页最终截图，孩子核对后一次提交；无法拍照时需说明原因，由家长人工核对。提交后可结束摄像头会话，但任务仍显示等待家长。家长查看截图、AI 清晰度与明显遗漏建议，以及该任务的辅导过程；可按需对最终截图发起完整逐题批改，在原图标记上查看并校对结果。家长逐项确认或写明原因退回，也可批量确认。退回任务重新提醒孩子补做和再提交。逾期仍可提交；是否按时以首次提交时间计算，家长可修改截止时间。未确认任务在创建满 60 天前提醒家长，到期删除内容并仅记未确认数量。系统通知推送仍待后续实现，当前提醒依赖应用在前台。

清晰完整的电子作业、屏幕题图及截图按题目内容分页；模糊、遮挡或不能可靠定界时仍需重拍。提交时科目匹配可去除明确年级／学段／册次，并识别“奥数→数学”“英文→英语”；自由科目按完整名称精确匹配，不把“数学与语文”当数学。部分异科目页会明确提示未加入；全部不符时提示换页，不误报已经拍过。

作业计时从孩子进入作业状态后开始，默认用正计时和可调整的参考目标；达到目标只提醒一次，不自动结束。首次按年龄段和未完成任务数给出试用目标，近七天有足够同科目记录后使用个人历史中位数。孩子可说“做了多久”“目标改成三十分钟”“切换到语文作业”，也可点击纸面左侧的半透明计时浮层；家长能在手机端修改目标。独立作业和辅导互动计入学习时间，批改等待与暂停单列。科目优先取孩子选择的任务，其次取当前纸面识别；不确定时归入“待归类”。计时数字每秒刷新，前台计时每 5 秒保存在本机、约每分钟同步服务端，暂停或结束时立即补传；断网时保存在本机并在恢复后按序补传，后台和应用关闭期间不补算。计时记录与会话一同按 60 天规则清理，旧会话的墙上时长单列为“含暂停的旧记录”。

家长日报按手机本地自然日汇总提交、确认、退回的去重任务数，逐页批改、观察和孩子自述按同一天筛选；家庭待确认任务与累计待核对观察另列，不混成今日完成量。结束页的“本次作业回顾”只统计当前会话的求助和关联提交任务，引用孩子自述或已核对观察，再给一条有来源的下一步建议。没有证据时保持中性；旧记录缺失事件时间或会话关联时不补猜，也不把新字迹、求助次数或任务完成解释为已经掌握。不新增模型调用、复习模块或学习画像。

自动卡题提醒可由家长设为关闭、少提醒或标准；孩子只控制当前会话是否开启，家长关闭优先。它在本机低分辨率观察纸面活动，达到同题停留与无可见进展门槛后才上传前后两张缩放纸面图核对；起步时没有足够动作定位题目，也会在标准档约 3 分钟后先核对整页是否出现新作答，再温和询问是否需要帮助。若整页进度能可靠定位唯一小题，问询时会在冻结画面上逐渐圈出题目；不能确定时只作通用问询，不猜题。孩子主动求助始终可用。具体门槛和教学依据见 [教师式学习陪伴](docs/teacher-led-learning.md)。家长首页还显示大模型 Token 的今日、本月、累计用量及调用次数，按手机本地日期划分；只累加服务商实际返回的用量，未返回用量的调用另行计数。累计值从启用本功能后开始记录，无法补算旧调用；用量记录不包含题目或图像，为支持累计统计会保留至家长手动清除家庭记录时一并删除。

批改结果把孩子纸面答案与标准答案（开放题为参考表达）分开，逐题给出解题思路、可复核步骤和作答对照；图形有助于讲解时可显示非按比例的矢量示意图。题干、答案或解法不可靠时不显示猜测的参考解答。批改结果提供单题复检：点击截图上的题目标记，在对照浮层中发起复检。服务端用本次保存的整页图和该题附近放大图重新核对；最新复检成为当前标记与题目状态，原判及其依据保留供对照。家长可在同一浮层更正单题判断、纸面答案和标记位置，附说明并保留历史；后续 AI 复检只提供建议，不覆盖家长校对。播报字幕中的可执行词和回应词可直接点击，另有重播与单次语音互动按钮；点击回应仍走相同的确认与授权流程。

正在陪伴时，孩子用手指画线、圈画或勾勒一道题，停笔约 1.2 秒后自动请求图上讲解；连续补画会重新计时，不必再点“提示”。讲解按短语音片段逐步写出笔迹，语音“重看图示”可重播，“返回实时画面”可收起；明确口头问题播报后才自动短时收音，建议动笔时保持安静；系统语音服务失败后不自动连续重连。家长退回作业时可生成孩子可读的补做建议，编辑确认后才展示给孩子；仍可自行填写。

自动观察和提示使用的纸面 JPEG 仅在请求期间送至配置的第三方模型，不持久保存。孩子点击一次“批改作业”后，系统在纸面稳定时识别并裁剪一页或双页；翻页继续收集，自动去重并尝试读出科目、页码。孩子核对缩略图和页数后一次确认，家长授权后逐页给出已答题的批改、正确解法和书写步骤分析。密集的竖版页面会在服务端放大上下区域并合并纸面坐标，用户仍只提交一次。每页结果只绑定该页截图供家长复核；单页走同一快捷流程。未覆盖或看不清的题目会明确提示；点击截图标记会打开半透明对照浮层，原图与孩子答案、纸面依据、解题思路同时可见，不会滚动跳走。密集题页可隐藏标记查看原图。批改截图、文本和任务记录最多保留 60 天后删除，家长可提前删除。截图通过家庭鉴权接口读取，不随看板数据下发。音视频通过 WebRTC 按需传输，不录制；孩子口述思路以自述文本单独记录。主动语音指令在按住说话时收音；应用提出明确问题且麦克风已授权时，先播报，再自动开启初始 15 秒回应收音，讲话后跨短暂停顿继续收集并延长窗口；播报期间可点击回应词或语音按钮停播并立即操作，超时或进入后台即停麦；可回答词在字幕和收音状态中突出显示。家长主动接通语音通话后才持续传音，结束通话即停麦。Android 指令识别优先使用设备端服务；本地不可用时尝试系统默认服务，其音频处理方式取决于设备服务商。家长批准后，孩子可在当前会话内批改 10 分钟，家长可随时撤销；纸面标记位置由 AI 估计，无法定位时标为不确定。完成状态由孩子提交最终截图、家长核对后确认；退回后孩子补做并再次提交。当前支持单家庭试点；自动翻页捕获、跨网直播、摄像头发热、语音识别准确度和三年龄段教学质量仍需真机与真实作业验收。
